1. Для реализации микрофронтенда был выбран Webpack Module Federation из-за простоты в использовании, он позволит расширять микрофронтенды, добавлять динамические импорты и подключать новые микросервисы за достаточно короткий срок.
Монолитный фронтенд был раздеден на:
Host - агрегатор
Auth-microfrontend - Сервис авторизации
Profile-microfrontend - Сервис профиля пользователя
Card-microfrontend - Сервис карточек
Common - общие компоненты (в данном случае popup)

Компоненты были разделены в соответсвии с их доменами, модули можно масшатбировать независимо друг от друга, а модуль common позволит избежать дублирования кода.

(Запуск на текущий момент не возможен) Запуск осуществляется посредствам включения всех модулей (npm start)
